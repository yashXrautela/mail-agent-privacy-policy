Mail Agent Privacy Policy

Last updated: September 10, 2026

Mail Agent is an application that helps users organize and summarize their Gmail messages using automated processing and artificial intelligence.

1. Information We Access

When you authorize Mail Agent through Google OAuth, the application may access information from your Gmail account, including email messages, subjects, sender and recipient information, timestamps, message identifiers, and related metadata.

2. How We Use Gmail Data

Gmail data accessed by Mail Agent is used only to provide the application's functionality. This includes retrieving authorized emails, processing email information, organizing messages, and generating email summaries.

Mail Agent does not sell Gmail data or use Gmail data for advertising.

3. AI Processing

Mail Agent may use Google's Gemini API to process email content and generate AI-powered summaries.

Email information may be transmitted to the AI service when necessary to provide the requested functionality.

4. Data Storage

Mail Agent may store information required to provide its functionality, such as processed email information, summaries, message identifiers, and application data.

OAuth credentials and authentication tokens are used only to maintain the authorized connection to the user's Google account and are not sold or shared for advertising purposes.

5. Data Sharing

Mail Agent does not sell, rent, or trade users' personal information.

Information may be transmitted to services required for the application's functionality, including:

  • Google Gmail API — to access authorized Gmail data.
  • Google Gemini API — to process email content and generate summaries.

6. Data Security

Reasonable technical measures are used to protect information processed by Mail Agent. However, no method of electronic transmission or storage can be guaranteed to be completely secure.

7. Data Retention and Deletion

Mail Agent retains application data only as long as reasonably necessary to provide its functionality or for legitimate technical purposes.

Users may revoke Mail Agent's access to their Google account at any time through their Google Account settings.

Users may request deletion of application data by contacting the developer using the contact information below.

8. Google API Services User Data Policy

Mail Agent's use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Mail Agent uses Google user data only to provide the functionality requested by the user and does not sell Google user data.

9. Children's Privacy

Mail Agent is not intended for children under the age of 13, and the application does not knowingly collect personal information from children under 13.

10. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the application or its data practices. Any changes will be posted on this page with an updated "Last updated" date.
